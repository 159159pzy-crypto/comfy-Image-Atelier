# ComfyUI 工作流 v2 安装与升级

本文说明如何把附件 `D:\loud\workflow (1).json` 接入 Anima Random Studio。附件中的 MarkdownNote 只作为工作流说明；实际设置、校验和提交以仓库代码及 API Format 模板为准。

## 文件关系

- `D:\loud\workflow (1).json`：ComfyUI 前端工作流基线，用于在 ComfyUI 中查看节点、手工调试和回滚。
- `templates/workflow_api_v2.json`：从同一基线导出的 API Format 提交模板。提交时由渲染器按模型档案、LoRA、提示词、底图模式和修复开关填写。
- `templates/workflow_api.json` / `templates/workflow_ui.json`：旧版 Anima 模板，保留给历史 PNG 工作流和升级兼容路径；不应作为 v2 新提交的基线。

不要只复制前端 JSON 到 `/prompt`；ComfyUI 的 `/prompt` 接受 API Format。更新附件后，在 ComfyUI 中重新导出 API Format，检查每个节点都有 `class_type`，并覆盖 `templates/workflow_api_v2.json`。保留前端 JSON 副本，避免 API 导出时丢失可视化信息。

## 首次安装

1. 启动 ComfyUI，打开 `/object_info`，确认 `UNETLoader`、`CLIPLoader`、`VAELoader`、采样器和基础提示词节点可用。
2. 将附件工作流导入 ComfyUI，检查自定义节点。v2 所需节点包包括 ComfyUI-Aaalice-Nodes、Prompt Assistant、Krea Seed Variance Enhancer、KJNodes 和 Lora Manager；SeedVR2 随 ComfyUI 提供。N 卡放大和 `ForbiddenVisionFaceProcessorIntegrated` 是可选插件，缺少时可以关闭对应阶段，不能用旧高清节点代替。
3. 将档案资源放到 ComfyUI 当前配置实际扫描的目录（可由 `extra_model_paths.yaml` 改变）：
   - Anima：`anima-base-v1.0.safetensors`、`qwen_3_06b_base.safetensors`、`qwen_image_vae.safetensors`。
   - Krea 2：`krea2_turbo_int8_convrot.safetensors`、`qwen3vl_4b_fp8_scaled.safetensors`、`qwen_image_vae.safetensors`。
   - SeedVR2：`seedvr2_3b_int8_convrot.safetensors`、`ema_vae_fp16.safetensors`（启用 SeedVR2 时）。
4. 启动本项目：

   ```powershell
   python run.py --comfy-url http://127.0.0.1:8188
   ```

5. 打开 `http://127.0.0.1:8190`，刷新资源。`/api/resources` 会返回两个档案的绑定文件、SeedVR2 文件、节点和插件状态。缺失文件不会被自动改名或替换。

## 模型切换和提示词池

主模型可在当前档案已分配的 UNet 中单独选择；切换档案仍会更换 CLIP、VAE、编码类型、采样默认值和命名空间。SeedVR2 模型/VAE 从 ComfyUI 实际清单选择，档案资源作为默认值。

模型切换是档案切换，不是只换 UNet：UNet、CLIP、VAE、编码类型、采样默认值、底图默认值和 SeedVR2 资源会一起切换。Anima 的五类 Tag 池继续使用 `prompt_seed` 确定性抽取；Krea 2 使用隔离的自然语言池，首版为空。

可通过 API 导入 Krea 2 词池：

```powershell
$json = @{ model_profile = 'krea2'; mode = 'append'; items = @(
  'a cinematic natural-language prompt',
  'a quiet studio portrait with warm window light'
) } | ConvertTo-Json
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8190/api/prompt-pools/import -ContentType 'application/json' -Body $json
Invoke-RestMethod http://127.0.0.1:8190/api/prompt-pools?model_profile=krea2
```

也可以在前端导入 JSON 字符串数组或 CSV（每行一条）。词池、LoRA 触发词和风格预设带 `model_profile` 命名空间；升级前旧全局文件会写出备份，旧数据映射到 Anima。

## 修复链验收顺序

采样参数中的修复设置对应 API `upscalers`：

- `latent` 包含倍率、放大方法，以及 `second_sampler` 的步数、CFG、Sampler、Scheduler、Denoise。二次采样复用当前主模型、CLIP、VAE 和 LoRA；关闭它时潜变量直接送入 VAE 解码。
- `seedvr2` 包含模型、VAE、倍率、权重类型、色彩校正、编码/解码分块参数和独立 KSampler 参数。
- `nvidia` 包含 `resize_type`、倍率和质量档位，直接绑定 `RTXVideoSuperResolution`，不虚构独立模型文件。
- `face_refine` 暴露 `ForbiddenVisionFaceProcessorIntegrated` 的采样、检测、裁切、遮罩、提示词、色彩、分割和卸载参数。

修复阶段只允许按以下顺序串联，任何阶段都可以关闭：

1. 底图：普通底图或底图－双采样器（二选一）。
2. 潜空间放大。
3. SeedVR2 修复放大。
4. N 卡放大。
5. Forbidden Vision 脸部细化。

先关闭全部可选阶段生成最小批次，再一次只开启一个阶段。提交前资源预检必须报告缺失模型或节点；N 卡与脸部细化只检查节点/插件状态，不扫描独立放大或检测模型文件。阶段关闭后 API payload 不应留下孤立节点。v2 删除 CFGZeroStar、`UpscaleModelLoader` / `ImageUpscaleWithModel` 高清链和独立 ADetailer，局部重绘等其他原有功能仍由附件工作流负责。

## 升级和回滚

旧顶层 `second_sampler` 迁入 `upscalers.latent.second_sampler`；旧 `hires` 仍迁入潜空间放大。v2 的新设置不再保存这些旧顶层字段。

1. 停止 WebUI，备份 `data/style_presets.json`、`data/lora_trigger_overrides.json`、浏览器草稿和附件前端工作流。
2. 更新代码和 `templates/workflow_api_v2.json`，不要覆盖附件前端基线。
3. 首次启动会迁移设置：`model_name` 映射到 Anima；旧 `hires` 映射为潜空间放大；`detailers`、`cfg_zero_star` 和独立 `second_sampler` 被丢弃。迁移后的设置不再保存这些字段。
4. 逐档案检查资源和词池，再运行测试：

   ```powershell
   python -m pytest -q
   node --check static/app.js
   ```

5. 若 v2 API 导出与 ComfyUI 版本不兼容，恢复附件前端基线和备份数据，并临时使用兼容模板；不要把旧节点手工拼入 v2 payload。

历史记录保存模型档案、实际资源、最终正负提示词、池选择和双种子。回放使用保存的冻结提示词和原始种子，不受后续词池编辑影响。
