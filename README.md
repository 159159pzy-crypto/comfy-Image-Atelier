# Anima Random Studio · 1.2.0

基于 [ComfyUI](https://github.com/Comfy-Org/ComfyUI) 的本地生图工作台，把单图创作、随机批量生成、模型与 LoRA 配置、提示词收藏和作品历史放在同一个界面中。支持 **Anima / Krea 2** 两套模型档案，并提供 Windows 启动器，用于安装环境、管理服务和更新工作台。

## 1.2.0 更新介绍

本版在 1.1.0 基础上完善安装与更新流程，新增图像反推，并调整参数面板、作品预览和界面动效。

- **启动器内更新与单文件发布**：在设置中检查、下载并重启更新；提供安装版、独立 EXE，以及仅含 EXE 的 ZIP。
- **六步安装向导**：支持新建或导入 ComfyUI、下载与空间检查、暂停续装和失败重试；可选下载 Krea 2、SeedVR2 和本地反推模型，并加入可跳过的提示词助手供应商配置。
- **图像反推台**：支持元数据提取、视觉 AI 和本地标签，结果可编辑、复制、应用及撤销；Anima 与 Krea 2 分别保存图片、选项和任务，支持取消及刷新恢复。
- **参数与处理顺序统一**：精简单图与随机工作台参数，普通底图和双采样各自保存编辑值；恢复底图、潜空间、脸部、SeedVR2、N 卡及 DLSS 的处理顺序，接通底图降噪、K2 多样性增强与随机台固定图像种子。
- **作品预览与详情**：历史卡片使用轻量缩略图，大图按原图尺寸缩放至 400%；单图详情采用紧凑布局，两个工作台均可定位原图所在文件夹。
- **界面与动效**：弹窗、滑轨和折叠区支持连续操作与中途切换；作品库和队列轮询复用现有内容，随机台底栏精简并适配窄屏，补齐减少动态效果、高对比度等显示设置。

## 界面与功能

以下三张截图展示当前工作台。截图中的模型、LoRA、词条和参数为示例，实际可选内容取决于你的本地环境。

### 单图创作：从描述到细调

单图工作台适合已经有明确画面想法的创作：左侧编辑提示词和参数，右侧查看生成预览与进度。

![单图创作工作台：提示词编辑、共享收藏与生成预览](docs/screenshots/anima-studio-single-workbench.png)

- **分开编辑提示词**：画面描述、负面提示词、前缀和后缀各有独立输入区，便于保留常用风格和质量词。
- **提示词重写台**：在「提示词处理」中独立填写初始文本，选择服务、模型和系统提示词后主动重写。结果可编辑，再追加到或替换正向正文；前缀、后缀、负向词保持原样，并可撤销应用。Anima 与 Krea 2 分别记住重写草稿，点击生成不会自动运行重写。
- **图像反推台**：通过小滑轨切换到反推台，提供元数据提取、视觉 AI、本地标签三种方式。拖入图片只提取内嵌提示词；没有可用正向词时，由你选择视觉 AI 或本地标签并点击开始识别。正负提示词可分别编辑、复制和应用，生成参数只读展示，多组工作流提示词需选择后应用。Anima / Krea 2 分别保存图片引用、各方式的选项、结果和运行任务。
- **共享收藏**：Anima 与 Krea 2 分别保存收藏；同一模型档案的单图与随机工作台共用条目和分组。Anima 保留五类内容及画师收藏，Krea 2 使用独立的自然语言收藏。
- **直接收藏提示词**：在提示词框中选中文字后点击「收藏提示词」；没有选区时保存最近编辑框的整段内容。可修改名称、正文和分组，Anima 还需选择内容分类。收藏只保存文本，不保存整套生成参数。
- **参考图输入**：支持选择文件、拖入参考图识别框或聚焦框后粘贴图片，添加后切换为图生图。反推台有独立识别框，框外拖放不会上传或切换生图模式。支持单帧 PNG / JPEG / WebP，单张最大 20 MiB、4000 万像素，可调整降噪强度和尺寸适配方式。
- **图生图强度**：降噪越低越保留原图；不同模型对同一数值的重绘程度可能不同，潜空间二次采样等后处理还会继续改变画面。降噪为 0 时，基础阶段只做 VAE 编解码重建，后处理仍按配置执行。默认强度和已有草稿保持不变。
- **预览与继续创作**：查看采样进度和生成结果，点击图片打开详情及大图；历史作品可送到单图工作台继续编辑，也可用作图生图参考。
- **紧凑生成详情**：单图详情与随机详情等宽，最大 1050px；预览铺满图片区，边缘可能裁切，点击可查看完整原图。摘要分为主模型、生成／采样与种子、底图与最终尺寸三行；常用操作保持可见，长提示词与完整参数按组折叠，需要时展开查看。

### 常用参数：模型、LoRA 与采样集中配置

常用参数面板把模型选择和 LoRA 列表放在一侧，把尺寸、采样与种子设置放在另一侧，方便逐项调整。

![常用参数面板：模型档案、LoRA 权重、采样参数与随机种子](docs/screenshots/anima-studio-common-parameters.png)

| 配置项 | 支持内容 |
| --- | --- |
| 模型档案 | Anima / Krea 2，按档案关联模型、文本编码器与 VAE 等资源 |
| LoRA | 多个 LoRA 组合、独立启停、权重调整、排序、移除及触发词管理 |
| 采样参数 | 宽高、步数、CFG、采样器、调度器；普通底图另有降噪幅度 |
| 底图模式 | 普通底图与双采样互斥显示，各自保存编辑值；双采样包含总步数、切换步数、潜空间倍率与缩放方法、两段 CFG / 采样器 / 调度器 |
| 随机种子 | 两个工作台均可每次随机或固定图像种子；新草稿默认固定 0，随机台固定图像种子仍逐张抽取提示词 |
| 放大与修复 | 按底图 → 潜空间放大 → 脸部细化 → SeedVR2 → N 卡放大及 DLSS 的顺序执行，可独立关闭各处理模块 |

建议首次先用普通底图完成一次基础生成，再逐项启用放大或修复。未安装可选高清模型时，可以关闭对应功能使用基础生成。

单图与随机工作台分别保存 Anima / Krea 2 的参数草稿；首次进入使用对应默认值，再次切回恢复上次配置。已加载的模型和 LoRA 清单在当前页面内复用；新增文件或修改分类后，可在资源分类面板手动刷新，生成前仍会检查实际资源。

单图工作台通过「风格预设」保存和应用参数组合。「兼容设置」仅在存在隐藏参数的非默认保留值或非零提示词种子时显示，恢复精简参数默认值后自动隐藏。放大修复模块通过开关和参数展开表示开启，卡片保持中性边框。

普通底图与双采样均提供「K2 多样性增强」开关，仅 Krea 2 可开启，新配置默认关闭。旧草稿和预设中的增强细项继续保留；旧随机 Krea 2 配置恢复其原本启用增强的行为。

新配置的普通底图默认 20 步、CFG 8、euler / simple、降噪 1；双采样默认总步数 30、切换步数 15，两段均为 CFG 8、euler / simple。双采样沿用原工作流的第一段完整采样、第二段从切换步继续，默认实际为 30＋15 步。潜空间默认放大 1.5 倍、Wan 2.1、20 步、CFG 8、euler / simple、降噪 1。「缩放方法」中的 Wan 2.1 等选项是 Sesqui 的模型格式，支持 1–2 倍；已有配置中的其他算法仍保留。

脸部细化只显示步数、CFG、采样器、调度器与降噪，默认 8、1、res_2m_ode、beta57、0.3。SeedVR2 只显示模型、配套 VAE、颜色匹配方法与倍率，默认 seedvr2_3b_int8_convrot.safetensors、ema_vae_fp16.safetensors、lab、2 倍。N 卡放大只显示倍率、风格、强度、局部光影、局部细节与输出混合，默认 2 倍、电影及四项强度 1；DLSS 位于 RTX 放大之后，随 N 卡模块一起启停。

默认采样器或调度器未安装时，界面保留原值并标记缺失，不会自动替换；只有启用对应模块时才阻止生成。旧配置的内部参数不因面板精简而丢失，图生图参考图的重绘强度仍独立保存。历史复现保留原提示词、参数和双种子，但统一使用恢复后的处理顺序，因此涉及后处理的旧图可能与升级前不同。

### 提示词规范、AI 重写与图像反推

Krea 2 的基础规范只整理首尾、行尾空白和换行编码，保留大小写、段落、专有名称、数字、标点、下划线与重复表达。Anima 继续使用 Tag 规则；两个档案的规则开关和自定义替换分别保存。Krea 2 的自定义替换匹配完整文本、区分大小写，不拆分逗号或句子。旧规则文件迁移至 Anima 前会保留 `.v1.bak` 备份。

单图点击「规范提示词」手动整理，随机工作台在编辑结束后自动整理。基础规范在本地完成，不调用 LLM。单图重写台的「读取当前提示词」只复制正向正文到初始输入，不会立即发起请求；AI 结果只有在点击追加或替换时才进入生图输入。

先启动 ComfyUI，再打开启动器「设置 → 提示词助手」管理供应商、模型与多套系统提示词。配置沿用 Prompt Assistant 插件，支持其 OpenAI 兼容服务和 Ollama；工作台刷新选项后即可选用。密钥继续由插件存储，不使用 Windows 凭据管理器；编辑时密钥框留空保留已有值，清除需要单独操作。

重写和视觉 AI 使用所选模板的内容快照，并统一附加当前模型的输出规范：Anima 生成英文标签，Krea 2 生成英文自然语言，同时生成中文名称与补充说明。后台校验结构后，现有结果框仍只显示可编辑的提示词正文。格式错误会明确提示并保留原预览，不自动再次调用 AI；旧任务、元数据提取和本地标签继续使用原流程。缺少模板或纯模板兼容能力会明确报错。首次安装兼容补丁后需要重启 ComfyUI，安装与源码修复方法见[启动器说明](launcher/README.md)。

视觉 AI 使用 Prompt Assistant 的视觉模型与视觉模板，在启动器中切换到「图像反推」配置。工作台另提供 Anima 英文标签、Krea 2 英文自然语言两套内置模板，支持随机或固定视觉种子。固定种子只控制反推节点，不会更改生图种子，也不保证远端服务返回完全相同的文字。

本地标签复用源工作流的 `WDTimmTagger`，提供模型、普通标签阈值、角色阈值和排除标签。默认使用 PixAI 0.9 与源工作流的阈值和排除词。先在启动器「本地反推模型」组按需下载模型包；只有权重、配置、标签表及模型所需额外文件全部校验完成后才能识别。预设模型锁定版本并校验 SHA-256，不会自动下载全部模型。手工安装模型可检测使用，未完整准备时保留图片并提示修复；识别任务不负责首次下载。

新图片和省略 `method` 的反推请求都只提取元数据。没有可用提示词时等待手动选择模型方式，切换方式及刷新页面不会自动调用模型。已有元数据始终优先，不要求 ComfyUI、视觉服务或本地模型在线。重写和反推均支持取消和刷新恢复；每个模型档案同时最多运行一个反推任务，发送到 ComfyUI 后最多等待 300 秒。视觉 AI 和本地标签的识别设置单独展示，不当作图片原始生成参数。

元数据在原图重编码前读取，支持本项目记录，以及 [Stable Diffusion Prompt Reader](https://github.com/receyuki/stable-diffusion-prompt-reader) 已支持的 A1111、Easy Diffusion、StableSwarmUI、Fooocus-MRE、NovelAI、InvokeAI、ComfyUI、Draw Things、Naifu 图像格式和旧版变体。复杂自定义工作流或缺失元数据可能无法恢复原提示词，此时可手动选择模型识别，结果明确标记来源。模型识别不恢复或编造原始负向词、种子、采样参数；可提取的生成参数也不会自动套用到生图设置。

旧扩写与 OC 配置不再自动参与普通单图生成，已有处理结果作为重写台预览保留，应用前不会覆盖原正文。历史复现及同提示词变体继续使用保存的最终文本，不重新请求 AI。重写任务加入现有队列，支持取消；发送到 ComfyUI 后最多等待 300 秒。

### 随机工作台：组合词池，批量探索

随机工作台将生成设置、作品库和批次控制放在同一页面，适合固定部分内容、让其他内容随机变化。

![随机工作台：提示词池、作品库与批量生成进度](docs/screenshots/anima-studio-random-workbench.png)

- **五类内容池**：Anima 支持角色、服装、姿势、背景、表情五个维度，并可设置人物构成、画师与风格预设。
- **每个维度独立控制**：可选择「关闭」「随机池」或「固定」，组合固定提示词与随机候选。例如固定角色和服装，仅随机姿势与背景。
- **管理自己的词库**：支持筛选候选、排除不需要的内容、收藏分组、自定义词条，以及 JSON / CSV 批量导入。导入前先校验和预览，再处理冲突项。
- **Krea 2 独立词池**：自然语言条目包含名称、补充说明和正文，支持收藏分组、自定义分组树、搜索、收藏优先、批量收藏和 JSON / CSV 导入。导入弹窗提供模板、导入大项、已有分组多选与逐行冲突处理；同正文重复默认跳过，覆盖只更新名称、说明和分组。
- **批次与队列**：设置批次数量后连续生成；已有任务运行时可继续加入队列，并查看进度、管理等待任务或停止生成。桌面和手机上的随机台底栏均显示批次数量、任务进度与操作按钮，不显示实时缩略图；单图工作台仍提供大图实时预览。进度区显示模型与提示词准备、等待首步、分段采样及解码等阶段；采样步数按 ComfyUI 实际回报更新，首步计算期间不会显示虚构百分比。状态查询超时会自动重试。
- **作品库**：按来源筛选、分页浏览作品，查看文件名、种子、提示词与生成参数，再从历史结果继续创作。

单图工作台的「共享收藏」以紧凑标签显示：点击名称插入最近编辑的提示词框，点击爱心取消收藏。随机工作台通过池内侧栏管理收藏，不再提供独立共享收藏区域。收藏提示词时先选择目标池，保存当前选中文字或全文，并同时入池、收藏；Krea 2 固定自然语言池。保存不自动勾选候选或开启词池，已有全池模式仍包含新增条目。完整 AI 正文可自动带入名称和说明；手改、局部选取或混合追加后按普通文本收藏，不再次调用 AI。

停止生成时，支持定向取消的 ComfyUI 会取消本工作台的任务；旧版缺少该接口时只删除本任务的等待项，避免误停其他界面的任务。已在远端运行的任务可能继续执行，工作台会显示提示，需要时在 ComfyUI 中手动停止。选择保留的后续任务仍由 ComfyUI 按队列调度。

Krea 2 收藏保留保存时的名称、说明和正文快照，编辑或删除自然语言池词条不会改变收藏。池内收藏侧栏也显示尚未入池的旧收藏，标记为「仅收藏」；主动选用时才复用或恢复池条目，浏览和刷新不会写入。取消收藏不会删除词池条目。若出现「词条已保存，收藏待重试」，重试会复用原词条，避免重复创建。

Krea 2 标准导入示例：

```json
{"version":1,"items":[{"section":"prompt","title":"雨夜街景","subtitle":"霓虹灯下的城市夜景","prompt":"A rain-soaked city street illuminated by neon lights.","groups":["城市","夜景"]}]}
```

CSV 使用 `section,title,subtitle,prompt,groups` 列，多个分组用 `|` 分隔，含逗号或换行的正文按 CSV 规则加引号。旧字符串数组、逐行文本与 `text` 对象仍可导入；缺少名称时取正文首个非空行，说明留空。旧词池首次升级会备份后迁移，保留正文、条目 ID 和抽样顺序；备份或写回失败时保持可读并启用存储保护。整池替换需明确确认，只替换词条与自定义分组，保留收藏快照。

### 历史复现与变体有什么区别

| 操作 | 会保留或改变什么 |
| --- | --- |
| 复现此图 | 使用历史保存的最终正负提示词、生成设置和原种子重跑；会先检查所需模型、LoRA 和采样资源 |
| 同提示词变体 | 保留最终提示词，换一个图像种子重新生成；这是文生图变体，不是图生图 |
| 重抽指定内容 | 针对随机工作台记录，选择角色、服装、姿势、背景或表情重新抽取，其余内容按历史快照保留 |
| 按此配置再抽 | 复用原配置，重新抽取随机内容与种子，继续生成同类作品 |

具体可用操作取决于该条历史记录保存的信息和当前资源检查结果。缺少历史所需资源时会明确提示，不会自动换成其他模型；相同参数与种子也不代表跨模型版本、节点版本或硬件环境的逐像素一致。

单图与随机工作台的生成详情均提供「打开所在文件夹」，在本机 Windows 文件资源管理器中定位并选中该条历史记录的原图文件。此操作访问运行工作台的电脑上保存的原图，仅供本机访问使用；不接受自填路径，原图已移动、删除或无法访问时会明确提示。

历史卡片使用最长边 512px 的轻量缩略图；进入详情和大图后加载完整原图。大图默认适应窗口，双击或双触在适配与 100% 原始尺寸之间切换（一个原图像素对应一个 CSS 像素），滚轮或双指可继续放大至 400%，放大后可拖动。加减键缩放，0 恢复适配，Esc 退出；图片已完整以 100% 显示时，双击保持原尺寸。放大直接使用原图渲染，不经过缩略图。

缩略图按需生成并保存在数据目录的 `history-thumbnails/` 中，缓存上限 256 MiB、有效期 24 小时，可安全删除并自动重建；首次浏览需从 ComfyUI 读取原图，后续命中缓存时无需再次读取。此缓存不修改原图或历史记录；同名源文件在外部被覆盖后，缩略图最迟在缓存过期后更新。源码更新后需重启工作台后端并刷新网页，使缩略图接口与页面同时生效。

## 下载与启动（Windows）

### 1. 选择下载方式

从 [最新 Release](https://github.com/159159pzy-crypto/comfyui-random-image-generation/releases/latest) 下载（以下为 1.2.0 起的发布形式）：

- **安装版** `AnimaRandomStudio-Setup-win-x64.exe`：默认安装到当前用户的程序目录，也可选择其他位置；创建开始菜单入口，可选桌面快捷方式，无需管理员权限。
- **单文件版** `AnimaRandomStudio.exe`：下载后直接运行，无需安装。
- **ZIP 版** `AnimaRandomStudio-portable-win-x64.zip`：解压后只有同一份 `AnimaRandomStudio.exe`，适合下载或传输时使用压缩包。

页面底部的 Source code 是开发源码，不包含启动器。

### 2. 运行启动器

双击 `AnimaRandomStudio.exe`。启动器包含 .NET、Windows App Runtime 与应用资源，首次启动会自动提取到用户缓存，不需要在 EXE 旁保留 DLL 或资源目录。ComfyUI、节点和模型首次配置时另外准备。

适用于 **Windows 10/11 x64**。当前发布未签署代码签名；可使用 `SHA256SUMS.txt` 校验独立 EXE、ZIP 和安装程序。安装版卸载仅移除程序及快捷方式，保留配置、历史、模型和已下载环境。

### 3. 新建或导入环境

首次打开且尚未配置环境时会自动进入六步安装向导；已有环境时可从「安装环境」重新打开。按自己的情况选择：

| 方式 | 适合谁 | 操作要点 |
| --- | --- | --- |
| 新建环境 | 希望由启动器准备独立运行环境的用户 | 选择安装位置，先检查安装计划、下载内容和磁盘空间，再开始安装 |
| 导入已有 ComfyUI | 已有可正常运行的 ComfyUI 或便携版用户 | 选择 ComfyUI 目录或便携版父目录，检查识别到的 Python、节点与模型；特殊布局可手动指定 Python |

新建环境面向 NVIDIA 显卡，需要支持 CUDA 12.8 的驱动（570.65 或更新版本）和联网下载。已有其他显卡环境可尝试导入，兼容性取决于 ComfyUI 与所用节点。新建环境默认准备 Anima 基础模型；Krea 2、SeedVR2 和本地反推模型可在检查确认页按需勾选，也可稍后在「模型资源」中下载。可选模型默认不勾选。

下载中断后可继续或重试，已校验的资源会复用；环境安装完成后，可继续尚未完成的模型下载。遇到模型校验失败时，按界面提示处理对应文件。提示词助手供应商配置可以完成或跳过，之后仍可在设置中管理。

### 4. 启动工作台并生成第一张图

配置完成后在向导最后一步点击 **开始创作**，服务启动并通过连接检查后自动打开工作台；也可选择「稍后打开」，之后从「概览」点击 **启动工作台**。默认 ComfyUI 端口为 `8188`，工作台端口为 `8190`；使用默认配置时可在浏览器打开 `http://127.0.0.1:8190`。

1. 进入「单图」，选择已经准备好资源的模型档案和主模型。
2. 填写画面描述，检查宽高、步数、CFG 和采样器。
3. 首次使用先关闭尚未配置的放大与修复功能，点击「开始生成」。
4. 基础生成成功后，再添加 LoRA、参考图或切换到随机工作台进行批量探索。

关闭启动器窗口会收起到托盘；需要退出时，可在托盘菜单选择保留服务退出，或停止本程序启动的服务后退出。

## 启动器自动安装内容与可选项

以下内容按 **1.2.0 的安装清单**说明。在「安装环境」完成检查并开始安装后，启动器才会执行环境准备；仅打开 EXE 不会立即下载整套环境。

### 新建环境会自动准备什么

| 内容 | 自动处理方式 |
| --- | --- |
| Python | 安装 Python **3.11.9**，为 ComfyUI 创建独立的 `.venv` 虚拟环境 |
| 安装工具 | 下载并校验 **uv**；优先复用系统中可用的 Git，没有可用 Git 时下载隔离的 **MinGit** |
| ComfyUI | 拉取安装清单锁定的 ComfyUI 提交，并安装其 Python 依赖 |
| GPU 运行依赖 | 安装 **PyTorch 2.11.0、torchvision 0.26.0、torchaudio 2.11.0** 的 **CUDA 12.8** 版本 |
| 自定义节点 | 安装下面列出的 11 个节点，并执行其依赖安装步骤 |
| 基础模型 | 默认准备 Anima 底模、Qwen 文本编码器和 Qwen VAE，已有可复用文件会先检查 |
| 安装验证 | 检查关键依赖、PyTorch 的 GPU 可用性与 Python 包依赖一致性 |

新建环境会在所选安装位置下建立同级的 `ComfyUI` 和 `runtime` 目录：前者存放 ComfyUI、虚拟环境、节点和默认模型，后者存放安装工具、Python、下载缓存及临时文件。NVIDIA 显卡驱动需要自行安装或更新，启动器安装的是 Python 环境中的 CUDA 版 PyTorch，不会代装显卡驱动。

**导入已有环境的处理不同**：复用现有 ComfyUI、Python 和 GPU 运行时，补齐清单中缺失的节点及其依赖；用户原有、未由启动器托管的节点会保留，不强行升级。导入流程不会自动下载整套基础模型，缺少的可下载模型可在「模型资源」中勾选后下载。

### 随环境安装的 11 个节点

| 节点 | 主要用途 |
| --- | --- |
| `Comfyui-Anima-Tools` | Anima 提示词池与相关工具 |
| `rgthree-comfy` | 工作流切换与辅助控制 |
| `comfyui-impact-pack` | 工作流条件判断及修复相关节点 |
| `comfyui-impact-subpack` | Impact 配套检测节点 |
| `comfyui-easy-use` | 表达式计算等工作流辅助功能 |
| `ComfyUI-KJNodes` | 图像尺寸调整、模型传递和显存辅助节点 |
| `ComfyUI-Lora-Manager` | LoRA 加载、触发词及模型元数据管理 |
| `comfyui-aaalice-nodes` | 提示词选择、分组控制与分辨率预设 |
| `prompt-assistant` | 提示词重写与视觉反推节点；启动器分别管理文本和视觉模型、模板，工作台使用纯模板兼容补丁执行重写 |
| `ComfyUI-WD-Timm-Tagger` | 可选本地标签反推节点；未安装时只禁用本地标签，不影响其他功能 |
| `krea-seed-variance-enhancer` | Krea 种子变化增强节点 |

这些节点按清单统一安装，不是安装向导中可逐项取消的选项。**安装了节点不等于已经下载对应的可选模型**；新建环境中的 ComfyUI 和节点版本按清单锁定，便于恢复安装。完整版本和来源见 [运行环境清单](launcher/manifests/launcher-manifest.json)。

### 默认自动下载的 Anima 基础模型

| 用途 | 文件名 | 默认目录（相对 ComfyUI） | 文件大小约 |
| --- | --- | --- | --- |
| Anima 底模 | `anima-base-v1.0.safetensors` | `models/diffusion_models` | 3.89 GiB |
| Qwen 文本编码器 | `qwen_3_06b_base.safetensors` | `models/text_encoders` | 1.11 GiB |
| 共享 VAE | `qwen_image_vae.safetensors` | `models/vae` | 242 MiB |

三项模型合计约 **5.24 GiB**，不包含 PyTorch、Python、节点依赖、缓存和解压空间；实际所需下载量与剩余磁盘空间以安装预检为准。自动下载文件会校验大小及 SHA-256。若配置了 `extra_model_paths.yaml`、多个模型目录或旧版 `unet` 路径，启动器会按 ComfyUI 实际路径扫描和定位资源。

### 可选模型与扩展资源

| 可选项 | 需要准备的文件 | 当前安装方式 |
| --- | --- | --- |
| Krea 2 | 底模 `krea2_turbo_int8_convrot.safetensors`、文本编码器 `qwen3vl_4b_fp8_scaled.safetensors`；复用上面的 Qwen VAE | 在安装向导或「模型资源」中按需选择下载，校验固定版本的大小及 SHA-256；也支持手动导入 |
| SeedVR2 修复放大 | 模型 `seedvr2_3b_int8_convrot.safetensors`、VAE `ema_vae_fp16.safetensors` | 在安装向导或「模型资源」中按需选择下载并校验，也支持手动导入；还需具备所用工作流要求的节点 |
| 自选底模与 LoRA | 用户自行选择的兼容模型及 LoRA | 手动添加；LoRA 默认放在 `models/loras`，启动器会扫描本地资源，不会自动下载截图中的 LoRA |
| 本地反推模型（可选） | PixAI、WD 与 OppaiOracle 共八个预设模型包 | 按需选择下载；推荐 `pixai-tagger-v0.9-timm`，整包校验通过后可用，不自动下载全部 |
| 其他放大、脸部检测或修复资源 | 以工作台所选功能的资源检查结果为准 | 当前自动下载清单不包含全部高级处理资源，需要按缺失提示另行准备 |

Krea 2 和 SeedVR2 使用清单中锁定的官方来源，下载前可通过「查看来源与授权」了解对应许可。手动添加时，底模放入有效的 `diffusion_models` 目录、文本编码器放入 `text_encoders`、VAE 放入 `vae`，随后重新扫描；运行中的 ComfyUI 可能需要重启才能刷新列表。

可自动下载的模型、文件名、来源和校验信息见 [模型清单](launcher/manifests/model-manifest.json)。

### 可以自行选择的安装与运行设置

- **安装方式与位置**：新建独立环境，或导入已有 ComfyUI / 便携版；新建时可选择存放环境、工具和缓存的磁盘。
- **下载来源**：提供官方来源、国内模型 / Python 镜像（Git 使用官方）、GitHub 镜像加国内模型 / Python 镜像，以及自定义来源。预设内容见 [下载来源清单](launcher/manifests/source-profiles.json)。
- **高级下载设置**：可指定 Git HTTPS 镜像模板、Hugging Face 镜像、Python 包索引，以及包含锁定提交的自定义 ComfyUI 仓库。设置仅用于本项目，不改写系统 Git / pip 配置。
- **导入环境的 Python**：默认自动识别 `.venv`、`venv` 和便携版 Python，识别失败时可手动指定解释器。
- **模型下载**：在「模型资源」中重新扫描，勾选支持自动下载且缺失的模型，再点击「下载所选模型」；也可使用「选择基础生成包」选择当前档案所需的可下载项。
- **运行设置**：可修改 ComfyUI / 工作台端口、界面主题，以及是否随启动器自动启动服务。

## 升级与数据备份

1. **软件内更新**：默认每 24 小时后台检查正式 Release，可在启动器「设置」中关闭自动检查或手动检查。查看版本说明后下载，支持暂停、续传和重试。下载不打断生图；完成后等待任务空闲，点击重启同时更新启动器和内置工作台。
2. **首次升级旧版**：1.1.0 及更早的启动器没有联网更新功能，需要最后一次下载 1.2.0 或更新版本；此后可在软件内更新。安装版与单文件版共享已有配置和数据。
3. **数据与回退**：升级前可在任务空闲、停止工作台后备份 `%LOCALAPPDATA%/AnimaRandomStudio`。完整更新成功后解除旧工作台固定回退，失败恢复原版本和原配置；工作台的「应用内置新版」与「回退上一版」仍可单独使用。更新前已停止的服务保持停止，无法安全停机时拒绝更新。

旧源码版的 `data` **不会自动迁入**启动器的数据位置。浏览器本地草稿与数据目录备份不同，更换浏览器或清除站点数据后不要依赖草稿恢复。

## 常见问题

**提示词池为空，或找不到 Anima Tools？**

确认节点已完整安装。标准目录、`-main`、`-master` 和改名目录均支持，不需要仅为去掉后缀重装；若提示重复目录或数据文件不完整，请先处理对应安装。

**模型或 LoRA 没有显示？**

在 ComfyUI 的 LoRA Manager 中完成扫描与基础模型分类，再回到工作台刷新分类。新增模型后可能需要重启 ComfyUI；同时检查所选模型档案是否与资源类型一致。

**生成失败，或提示缺少节点 / 模型？**

先关闭可选放大和修复，检查当前档案的基础模型与节点能否完成基础生成，再按日志补齐缺失项。模型文件存在并不代表对应节点已经安装。

**端口被占用，或启动器显示外部服务？**

检查已有 ComfyUI 和工作台是否仍在运行，确认环境与端口后按提示连接或修改配置；启动器不会随意停止不属于它的外部实例。
